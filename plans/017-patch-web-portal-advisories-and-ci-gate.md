## Why this matters

The root project gates dependency CVEs in CI (`npm audit --audit-level=high`),
but the `web-portal/` workspace is a separate npm package and is **never audited
in CI**. It currently ships **3 HIGH advisories** (all dev/build-time deps):

- `vite` 8.0.0–8.0.15 — `server.fs.deny` bypass on Windows alternate paths + `launch-editor` NTLMv2 hash disclosure via UNC path
- `ws` 8.0.0–8.20.1 (via `jsdom`) — memory-exhaustion DoS from tiny fragments
- `form-data` 4.0.0–4.0.5 — CRLF injection via unescaped multipart field names

plus 1 moderate (`js-yaml` quadratic-complexity DoS) and 1 low (`@babel/core`
arbitrary file read). **All are fixable with a non-breaking `npm audit fix`**
(no `--force` needed). Because nothing gates this, the next portal dependency
CVE will also land silently. This plan patches the lockfile and adds the missing
CI gate so regressions are caught.

## Steps

### Step 1: Patch the advisories

Run `(cd web-portal && npm audit fix)`. This must NOT require `--force`.

**Verify**: `(cd web-portal && npm audit --audit-level=high)` → exit 0 (0 high/critical). Moderate/low may remain; that is acceptable for the high gate.

### Step 2: Confirm the portal still builds and tests

**Verify**:
- `npm --prefix web-portal run typecheck` → exit 0
- `npm run test:portal` → all pass
- `npm run build:portal` → exit 0

### Step 3: Add a `security:audit` script to the portal package

In `web-portal/package.json`, add to the `scripts` object:
```json
"security:audit": "npm audit --audit-level=high"
```

**Verify**: `npm --prefix web-portal run security:audit` → exit 0.

### Step 4: Gate it in CI

In `.github/workflows/ci.yml`, in the Linux `verify` job, add a step immediately
after the existing `Security Audit` step (root audit, ~line 47):

```yaml
      - name: Portal Security Audit
        run: npm --prefix web-portal run security:audit
```

**Verify**: `grep -n "Portal Security Audit" .github/workflows/ci.yml` returns one match; the YAML is valid (indentation matches sibling steps — 6 spaces for `- name:`).
